# 插件作为子代理运行时配置的宿主

**Status**: accepted（2026-11-25）

## Context

运行时获取子代理配置（用户级/项目级定义、内置子代理模型覆盖、禁用清单）有两条来源。宿主未声明 `subagentRuntimeConfigEnabled` 时走文件回退：每次创建会话读一次磁盘，存量会话不再重读。宿主声明后，运行时在每个会话运行时创建时、以及每个回合开始时，反向请求宿主（`subagents/readRuntimeConfig`）要一份「已解析的完整快照」；快照按 strict schema 校验，错误应答会让建会话或整个回合直接失败。

插件此前走文件回退，设置页改完子代理定义或内置模型覆盖后必须新建会话才生效，与桌面端体验不一致。官方宿主（桌面端）走反向通道，用官方共享的 Markdown 解析器产出快照。

## Decision

插件接入反向通道：当代 CLI 认该能力时，插件在运行时偏好应答里声明 `subagentRuntimeConfigEnabled`，并作为 `subagents/readRuntimeConfig` 的宿主应答快照。

- 快照由插件自己读盘、解析。解析器是官方共享实现的逐函数移植（CLI 与桌面端共用同一份），等价性靠「官方实现生成的黄金样本回放」保证，而不只是单元测试；官方升级后重跑生成器即可发现解析器漂移。
- 应答永不回错误：读不出来一律回官方的内置回退形态（只用内置子代理）；自检不过的快照也不上线。
- 声明开关按「当代 CLI 内容确认认这个键」门控，探不动按不支持。两个方向的代价不对称：不声明只是回到文件回退（旧行为），声明错会让建会话全线失败。
- 内置子代理的模型覆盖必须带思考档位（运行时对缺档位的条目直接拒绝派生子代理）。写侧在「用户选了模型但请求没带档位」时补该模型档位集的末位，与官方桌面端同语义；读侧不替已有选择静默补档位，官方明确不做。
- 旧版 CLI 保持文件回退，设置页的生效时机文案按是否实时供给切换。

## Consequences

- 子代理定义、模型与思考深度改完对下一回合生效，无需重开会话；自定义子代理定义（包括桌面端写入的）同样实时。
- 插件成为其会话的子代理定义唯一解析方：移植的解析器必须跟随官方实现演进，这是一项持续的维护耦合，由黄金样本生成器承担回归检测。
- 会话的工作目录决定项目级定义取自哪里。运行时创建时才产生的子会话 id 反推不出父会话，只能落兜底目录（IDE 项目根）；该会话第一个回合开始时会再取一次，届时已可精确归属，所以只影响建会话瞬间的那一次读取。
- 每回合开始多一次本地读盘与解析（个位数小文件），不做文件监听缓存。

## Considered Options

- 切换会话时重建运行时（lifecycle restart）：不走反向通道，但要先验证重建对会话状态的影响，且当前会话内改完不生效，否决。
- 只修写入、维持新会话生效：改动最小，但与桌面端体验不一致，用户明确要求实时或切会话生效，否决。
- 快照固定回内置回退、不解析自定义定义：实现最简，但自定义子代理在插件的会话里全部消失，否决。
