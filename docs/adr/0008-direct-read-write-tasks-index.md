# 直接读写官方 tasks-index.sqlite 承载置顶与归档

**Status**: accepted（回溯记录，2026-11-12）

会话置顶、归档、未读等列表能力直接读写官方桌面端使用的本地 SQLite 索引库（tasks-index.sqlite），与官方客户端同库互通。既不走官方进程内存中的 sessions-index，也不等官方新增 API——置顶等能力根本没有协议方法。

**Considered Options**

- 只维护插件自己的索引：与官方桌面端、手机端不同步，置顶在别处消失。
- 只改官方进程内存：跨进程不可见，重启即丢。
- 等官方提供协议方法：能力长期缺席，无法排期。

**Consequences**

- 写入要与官方进程并发共存：更新带版本校验（CAS），删除按软删语义；自动归档的"判活"要对照 CLI 库的真实活动时间（双源取最大），否则会误归档活跃会话。
- 官方索引 schema 变化是隐性破坏面，升级桌面端后优先回归列表、置顶与归档。
- 插件补写的行如果只是静态快照，不能当作活动时间判据。

**References**

- 无内部设计文档；相关缺陷记录见 `docs/internal/bugs-regressions/`（自动归档误归档等）。
