# 公开主仓库与内部过程仓库的硬边界

**Status**: accepted（回溯记录，2026-11-12）

公开仓库只放可公开内容。协议逆向细节、抓包帧、凭证形态、含负结论的调研过程文档放在独立的私有仓库 `docs/internal/`，由主仓库 `.gitignore` 排除。这些内容一旦公开就不可撤回，而它们对公开使用者没有价值，因此边界是硬的，不做"挑着放"。

**Consequences**

- ADR 与 issue 正文必须脱敏；需要细节时只写指向内部文档的 References。
- 在本机运行的 agent 能读内部仓库，外部贡献者拿不到；这是有意的信息不对称。
- 构建、发版与插件运行都不得依赖 `docs/internal` 下的任何文件；它只服务于开发过程。
- 敏感图片与抓包产物在内部仓库内也要单独忽略。
